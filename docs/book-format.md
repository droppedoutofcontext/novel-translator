# Формат книги

Одна книга — каталог `books/<slug>/`. Slug состоит из строчных латинских букв, цифр и одиночных дефисов. Все файлы — UTF-8. В качестве рабочего образца можно использовать `examples/lighthouse/`.

## Профиль

```json
{
  "title": "Название перевода",
  "originalTitle": "Original title",
  "author": "Author",
  "sourceLanguage": "en",
  "targetLanguage": "ru",
  "original": {
    "url": "https://example.org/novel/",
    "adapter": "html",
    "allowedHosts": ["example.org"],
    "titleSelector": "h1",
    "contentSelector": "#chapter",
    "paragraphSelector": "p",
    "headingPattern": "Chapter\\s+(?P<number>[0-9]+)\\b\\s*[:.\\-–—]?\\s*(?P<title>.+)",
    "catalogue": {
      "path": "sources/catalogue.html",
      "url": "https://example.org/novel/"
    }
  },
  "reference": {
    "name": "Название референса",
    "path": "references/translation.txt",
    "notes": "Обращения и особенности оформления"
  },
  "chapterSources": {
    "1": {
      "title": "First light",
      "url": "https://example.org/novel/1.html",
      "input": "sources/chapter-1.html",
      "numbering": "Номер совпадает с заголовком оригинала"
    }
  }
}
```

Для сборки обязательно только непустое `title`. Остальные поля нужны для языка, перевода и получения исходников. Языки записываются кодами, например `zh-Hans`, `en`, `ja`, `ru`. `reference` может содержать ссылку `url`, локальный `path`, имя и заметки. `original` и `reference` — независимые источники; их нумерация может отличаться.

Пути внутри профиля считаются относительно каталога `book.json`. CLI-параметры путей считаются относительно текущего рабочего каталога, кроме стандартных `books/` и `dist/index.html`, привязанных к корню проекта.

## Адаптеры источников

### `html`

Адаптер извлекает один заголовок, один блок главы и абзацы внутри него. Значения по умолчанию: `h1`, `#chapter`, `p`; заголовок — `Chapter <number> <title>`.

Поддерживаются простые селекторы `tag`, `.class`, `#id`, `tag.class`, `tag#id`. Составные CSS-селекторы, XPath и JavaScript не поддерживаются. Скрипты, стили, `noscript` и `template` не входят в текст. Переносы `<br>` сохраняются внутри абзаца; HTML-сущности декодируются.

`headingPattern` — регулярное выражение Python, проверяемое на всём заголовке без учёта регистра. В нём обязательны именованные группы `number` и `title`. Например, для китайского заголовка:

```json
"headingPattern": "第\\s*(?P<number>[0-9]+)\\s*章\\s*(?P<title>.+)"
```

Если источник использует другую структуру, задай его селекторы и шаблон. Проверь результат через `--html`, прежде чем скачивать большой диапазон.

### `mangguo`

Готовый адаптер для глав Mangguo Shufang. Ожидает заголовок `第<number>章 <title>` и блоки `h3.j_chapterName`, `div.j_readContent`, `span.content-wrap`.

```json
"original": {
  "adapter": "mangguo",
  "allowedHosts": ["www.mangguoshufang.com", "mangguoshufang.com"]
}
```

В старых профилях без `adapter` он определяется по хосту источника. В новых профилях указывай адаптер явно.

### Ссылки и оглавление

`allowedHosts` задаёт список разрешённых хостов для получения главы и перенаправлений. Если поле отсутствует, используются хосты явно записанных URL в профиле. Для сетевой загрузки нужен HTTPS без пользовательских данных в URL и без нестандартного порта. Для `--html` сеть не используется и ссылка не обязательна.

`chapterSources` хранит проверенные соответствия номеров, названий и URL. Если для номера нет URL, скачиватель ищет его в локальном HTML-оглавлении `original.catalogue.path`. Ссылки раскрываются относительно `original.catalogue.url`. У каждой ссылки должен быть заголовок, соответствующий `headingPattern`. Противоречащие ссылки или названия приводят к ошибке.

Обнаруженные ссылки используются в памяти. Скачиватель не перезаписывает профиль книги; проверенные сведения можно добавить в `chapterSources` после сверки.

Для автопополнения можно указать `chapterSources.<номер>.path` — путь к локальному TXT или HTML относительно `book.json`. TXT содержит заголовок оригинала в первой строке, затем абзацы с пустыми строками между ними. HTML разбирается настроенным адаптером. Поле `input` остаётся описанием происхождения текста; `path` задаёт конкретный файл для автоматического чтения.

## Прогресс и запас глав

Локальный процесс `serve_reader.py` ведёт отдельный `reading.json` рядом с профилем:

```json
{"chapter": 100, "ahead": 30, "error": ""}
```

`chapter` — открытая глава, `ahead` — желаемое количество следующих глав, от 0 до 1000. Ноль выключает пополнение. `error` сохраняет причину паузы до явного продолжения. Состояние меняется в настройках читалки и не входит в Git. Файл не требуется для обычной сборки.

Запас считается последовательным: если готовы 101-я и 103-я главы, а 102-я отсутствует, перед читателем на 100-й главе есть только одна подряд готовая глава. Процесс сначала заполнит 102-ю. Для главы без исходника или неполного результата агента пополнение приостанавливается, готовые переводы сохраняются.

## Глоссарий и перевод

`glossary.md` — таблица `Оригинал | Перевод | Источник / статус`. Это референс для ИИ-агента; сборщик не делает автоматических замен по глоссарию.

Подтверждённым формам нужны ссылки или указания на локальный референс. Новые транскрипции отмечаются как рабочие. Контекст, род персонажа и варианты обращений можно описать в той же строке. Дополнительные предпочтения пользователя хранятся в `reference.notes`.

Файлы `chapters/1.md`, `chapters/2.md` и далее начинаются с `# Название главы`. Пустая строка разделяет абзацы; отдельный `* * *` означает смену сцены. Номер файла — положительный номер оригинала. Глава может начинаться с любого номера, пропуски допустимы. Файлы `1.md` и `01.md` одновременно запрещены как дубликаты.

## Карточки персонажей и пояснения

Необязательный `annotations.json` содержит массив карточек:

```json
[
  {
    "title": "Мара",
    "kind": "person",
    "forms": ["Мара", "Мары", "Маре"],
    "senses": [
      {
        "original": "Mara",
        "reading": "Мара",
        "body": "Смотрительница маяка.",
        "recap": {"chapter": 1, "text": "В первой главе она зажгла фонарь."},
        "passages": {"1": ["Мара зажгла фонарь"]}
      }
    ]
  }
]
```

`kind` — `person` или `reference`. `forms` задаёт точные формы для подсветки; учитываются границы слов и регистр не важен. Читалка не подбирает падежи автоматически.

В каждой главе отмечается только первое упоминание персонажа или отсылки; повторения остаются обычным текстом. Разные формы одного имени считаются одной подсказкой. Для одноимённых персонажей, различённых через `passages`, сохраняется по одной отметке на каждого.

Добавляй карточку, когда она помогает вспомнить редкого персонажа или понять нетривиальную отсылку. Общеупотребительные слова, понятные из абзаца действия и пояснения, повторяющие сам текст, не требуют отдельной подсказки.

`original` и `body` обязательны для каждого значения в `senses`. `reading`, `recap`, `passages` и `source` необязательны. `source` содержит строки `label` и `url`; в читалке открываются только ссылки HTTP(S).

Несколько значений нужны для разных персонажей с одинаковым именем. Если точная цитата из `passages` однозначно определяет персонажа в текущем абзаце, это значение показывается первым. Остальные доступны в раскрывающемся блоке. Текст `recap` показывается только после указанной главы. Основной `body` виден сразу: не помещай туда будущие спойлеры.
